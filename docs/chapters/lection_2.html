3  Лекция 2. F-статистика

3.1 Введение

Популяционная генетика изучает частоты аллелей в популяциях и различия между ними. Нас интересует частота аллелей — например, аллель, дающий нормальную лактазу, или аллель, определяющий окрас.

Мы хотим сравнивать частоты аллелей и находить разницу между популяциями.

3.2 Нуклеотидное разнообразие \(\pi\)

Пусть есть большая популяция с большим количеством представителей. Между любыми двумя представителями есть какое-то количество мутаций, которые их отличают. Между особями одного вида их мало, между особями разных видов — много.

Пример: три вида дрозофил. Пусть есть 6 особей одного вида, нас интересует попарное сравнение и вычисление среднего числа замен. Для этого расчёта нужно сделать \(\binom{6}{2} = 15\) сравнений, потом суммируем число отличающихся позиций, делим на 15 и нормализуем по длине самого гена.

Строго говоря, значение само по себе мало что даёт — важно сравнивать его между популяциями.

Эта метрика довольно простая, но её до сих пор используют в довольно серьёзных статьях.

Иногда считают Tajima’s D = \(\pi - \theta\) — разница наблюдаемого и ожидаемого нуклеотидного разнообразия (по какому-то референсу). Здесь число несёт уже больше смысла:

  • если меньше ожидаемого — есть очищающий отбор,
  • если больше — положительный отбор,
  • если равно ожидаемому — нейтральный (дрейф).

Иногда считают отдельно для синонимичных и несинонимичных замен.

3.3 Закон Харди-Вайнберга

\[p + q = 1\] \[p^2 + 2pq + q^2 = 1\]

Он довольно примитивен, но в реальности всё действительно сводится к нему.

Пример с медведями: белый окрас по рецессивному аллелю GG, а AG, AA — чёрные. Была вычислена частота аллелей: AA, AG, GG — 42, 24, 21.

Пусть \(p\) - частота аллеля \(A\), \(q\) - частота аллеля \(G\), \(N = 87\).

\[p = \frac{2AA}{2N} + \frac{AG}{2N} = \frac{42}{87} + \frac{24}{2 \cdot 87} = 0.62\] \[q = \frac{2GG}{2N} + \frac{AG}{2N} = \frac{21}{87} + \frac{24}{2 \cdot 87} = 0.38\]

\(2pq = 0.47\), но из наших данных должно быть \(24/87 = 0.28\) — меньше, чем ожидается. Видимо, гетерозиготам невыгодно быть? Это может указывать на отклонение от равновесия Харди-Вайнберга, например, из-за инбридинга или отбора.

А что если три аллеля? A, B, C:

\[p_a^2 + p_b^2 + p_c^2 + 2p_ap_b + 2p_bp_c + 2p_ap_c\]

Аналогично можно экстраполировать это всё на очень большое число аллелей, и закон всё ещё будет справедлив. На нём строятся более сложные статистики.

3.4 Родство

Identical by descent (IBD) — аллели, которые идентичны из-за наследования от общего предка.

\[F_{ij} = \frac{1}{4} r_1 + \frac{1}{2} r_2\]

где \(F_{ij}\) — мера родства между особями \(i\) и \(j\), \(r_1\) — вероятность, что 1 аллель IBD, \(r_2\) — вероятность, что 2 аллеля IBD.

Расчёт между отцом и сыном ничего не даёт — это сравнительная метрика.

3.5 Коэффициент инбридинга

Скрещивание близкородственных связей.

\[F = \sum \frac{1}{2^{n_i}} (1 + f_{A_i})\]

где \(f_{A_i}\) — коэффициент инбридинга для общего предка (например в случае Чарльза II — это были бабушка с дедушкой), сумма по количеству общих предков; \(n_i\) — длина пути от одного родителя к другому по генеалогическому дереву.

Через коэффициент инбридинга можно ввести обобщённый Харди-Вайнберг: \[f_{11} = (1 - F) \ldots\]

\[\hat{F} = \frac{H_e - H_o}{H_e} = 1 - \frac{H_o}{H_e}\]

где \(H_o\) — наблюдаемая доля гетерозигот, \(H_e\) — ожидаемая доля гетерозигот (через обычный Харди-Вайнберг).

Пример для эстеразы дрозофил:

AA — 0.6, AB — 0.2, BB — 0.2

\[H_o = 0.2\]

\[\hat{F} = ?\]

\[p = 0.6 + 0.2/2 = 0.7, \quad q = 0.2 + 0.2/2 = 0.3\] \[2pq = 0.42 = H_e\text{ — ожидаемое}\]

\[\hat{F} = 1 - \frac{0.2}{0.42} \approx 0.5\]

Есть определённые наиболее репрезентативные участки гомозиготности

3.6 Индексы фиксации (F-статистики)

\(H_i\) — индивид, \(H_s\) — субпопуляция, \(H_t\) — общая популяция.

\[F_{is} = 1 - \frac{H_i}{H_s}\] \[F_{it} = 1 - \frac{H_i}{H_t}\] \[F_{st} = 1 - \frac{H_s}{H_t}\]

Если \(H_s \approx H_t\), то \(F_{st} \approx 0\) — никакой дифференциации не происходило.

Эта метрика активно применяется в статьях. Для растений придумали эпи-Fst.

Пример: пусть есть популяция лемуров. Частота аллеля, характерная для вида, 20%, а в рассматриваемой ожидаемая частота 10%, а в итоге в популяции мы наблюдаем всего 9% гетерозиготных лемуров. Чему равны F-статистики?

\[p_t = 0.2, \quad q_t = 0.8\] \[p_s = 0.1, \quad q_s = 0.9\]

\[F_{st} = 1 - \frac{2p_sq_s}{2p_tq_t} = 1 - \frac{0.18}{0.32} = 1 - \frac{9}{16} \approx 0.44\]

\[2p_iq_i = 0.09 \implies F_{it} = 1 - \frac{0.09}{0.16} \approx 0.44\]

\[F_{is} = 1 - \frac{0.09}{0.09} = 0\]

3.7 AMOVA

Это ANOVA, которая использует в себе F-статистики. Обычно её не применяют.

3.8 Другие статистики

У F-статистик много критики, и вводили новые статистики: \(G_{st}\), Jost’s D, но их особо не приняли, и большинство использует \(F_{st}\).

3.9 Nick Patterson

h-index 130. Автор многих статистик.

3.9.1 F2

\[f_2(P_1, P_2) = E[(p_1 - p_2)^2]\]

— генетическая дисперсия между двумя популяциями.

\(f_2 = f(F_{st})\) — можно выразить через \(F_{st}\).

Сама по себе она не очень интересна — мы могли сравнить две популяции и через \(F_{st}\) через субпопуляцию.

3.9.2 F3

Есть два подхода:

  • С аутгруппой: \(f_3(O, A, B) = E[(p_O - p_A)(p_O - p_B)]\) — чем больше, тем ближе A к B.
  • Admixture: \(f_3(Test, Ref_1, Ref_2) = E[(p_{test} - p_{ref1})(p_{test} - p_{ref2})]\) — если < 0, была admixture (если > 0 — топология без смешения правильная).

Обычно смотрят на z-score по аллелям \((x - \bar{x})/\sigma\), потому что сами f3 статистики довольно маленькие, и есть эмпирическое правило: если \(|z\text{-score}| > 3\) — есть статистическая значимость.

Чтобы считать эти статистики, нужно хорошее покрытие — чтобы было много SNP.

3.9.3 F4-статистика

Хотим понять, к чему ближе A — к C или к D.

\[f_4(A, B, C, D) = E[(p_A - p_B)(p_C - p_D)]\]

Если существуют клады A, B и C, D — статистика близка к 0.

Если > 0, то A ближе к C. Если < 0, то A ближе к D.

F4-статистика потом свелась к ABBA-BABA тесту — просто нормализованная f4-статистика.

  1. a = d, b = c, a ≠ b [ABBA]
  2. a = c, b = d, a ≠ b [BABA]

\[D(A, B, C, D) = \frac{P(BABA) - P(ABBA)}{P(BABA) + P(ABBA)}\]

В некоторых тулах формула записана наоборот, и важно понимать, по какой формуле работает наш тул.

Эта статистика активно применяется. Есть кейсы с окраской уток, об окраске бабочек и сравнение европейцев и неандертальцев.

3.10 PCA

Есть критика — что этот метод сложно интерпретировать и что он старый — но всё равно он активно применяется, и включён в некоторые стандартные пайплайны обработки древних образцов

3.11 Кластеризация

STRUCTURE (байесовский — для небольших данных).

ADMIXTURE (ML, хорошо для больших данных).

Оценка количества популяций, которые надо смешать, чтобы получить данный образец.

Сейчас используют и другие тесты — маркеры крови и т.д.

3.12 Пакет ADMIXTOOLS qp

qpWave — сколько скрещиваний произошло в популяции.

qpAdm — насколько они были сильные.

Он умеет строить графики, где было смешение.
